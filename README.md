# 글로벌 공급망의 새 질서와 사모투자 (Navy XXIII)

JIT(Just-in-Time)에서 JIC(Just-in-Case)로. 지난 30년 자유무역 위에 지어진 글로벌 공급망이 안보·원가·진영의 논리로 다시 짜이고 있다. 재편의 배경과 충격의 연대기, 한국 제조업의 자리, 기업의 대응을 짚고, 이 변화가 사모투자 기회와 연기금 포트폴리오(TPA, 총포트폴리오 접근)에 무엇을 뜻하는지 정리한 101장 덱이다.

## 구성

1. 재편의 논리 — 자유무역 질서의 전제, MAGA와 고립주의, 가격에서 신뢰로
2. 원가의 논리 — BYD와 중국 생태계
3. 충격의 연대기 — 반도체 대란·요소수·희토류·호르무즈, 공급망의 급소 열세 곳
4. 한국 제조업 — 한·미·일 분업, 센카쿠·사드·일본 수출규제, FDPR, 한화 필리 조선소
5. 진영화의 확장 — AI 칩·전력망·해저케이블·항만 크레인·우주항공·바이오
6. 기업의 대응 — 미국 기업의 여섯 가지 전략, 프리미엄과 기대 손실
7. 사모투자 기회 — 다섯 갈래 투자 기회, 물류 자산, 정부 공동투자 구조
8. 기금 편입 (TPA) — 기준 포트폴리오와의 경쟁, 기금 안에 들이는 네 단계
